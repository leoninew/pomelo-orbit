# 前端单元测试实践

以当前生产代码的业务承诺为依据，使用已有 Vitest 工具链完成最小有效验证。先阅读 [项目约束](../../../AGENTS.md) 和相关实现、生产调用方；不要以历史测试反推已经移除的需求。

## 测试范围

- 保留业务规则、表单校验、数据转换、请求序列化、API 请求与错误契约，以及简单组件的输入、输出和基本操作测试。
- 优先主要正向流程和真实、高风险的失败边界。不穷举理论负向情况，不为不可达、系统不存储或已经移除的行为建立断言。
- 不编写并发、竞态、性能、集成、端到端或复杂 UI 测试。不通过整页挂载串联 Router、Store 和 API，不模拟终端或日志会话的完整生命周期、重连调度与流会话竞态，不验证 Tooltip 的布局、焦点、Portal 或第三方 UI 库内部行为。
- 不追求单元测试覆盖率，不设置覆盖率门槛，不增加覆盖率脚本或依赖，不为每个组件补测试。避免只复述实现、证明简单赋值或依赖内部调用顺序的断言。
- 按行为和测试边界判断价值，不因 `async`、`createApp`、mock 或文件长度直接删除测试。单个异步结果、工具函数的计时契约、解析器或缓冲区的业务规则仍可做轻量单元验证；不要扩展为并发或性能场景。测试执行器并行运行不属于并发测试，无需改成单线程。

## 编写与简化

- 将外部 API、导航及复杂子组件替换为局部替身，保留被测单元的真实逻辑。Router、Store、composable 可以独立测试，不要求挂载整页。
- 断言可观察的返回值、请求路径与载荷、状态变化、组件事件或简单字段反馈。API 测试使用请求函数或 Axios adapter 替身，不依赖真实后端。
- 使用项目正式语言包，避免手写不完整的翻译。复用现有挂载方式，只为需要 DOM 的测试启用 `happy-dom`，不额外引入整套 UI 测试框架。
- 卸载组件、移除挂载节点，并恢复本测试修改的 adapter、mock 和计时器，避免污染其他测试。

按需参考现有例子，不机械复制用例数量或结构：

- [componentForm.test.ts](../../../web/src/views/application/componentForm.test.ts)：按当前独立表单卡片验证校验与请求转换。
- [request.test.ts](../../../web/src/utils/request.test.ts)：通过 Axios adapter 替身验证请求和错误契约。
- [ComponentIdentityFields.test.ts](../../../web/src/components/application/ComponentIdentityFields.test.ts)：验证单个组件的字段错误与编辑反馈。

## 警告排查

检查警告时使用显式显示日志的命令：

```powershell
cd web
corepack yarn test --reporter=default --silent=false --no-color
```

当前 Vitest 在 agent 环境可能默认使用隐藏已通过用例日志的 reporter；普通运行显示通过，不能证明没有警告。

- 将每条警告定位到用例和实际来源。缺翻译、未匹配路由、缺注入或残留挂载等测试环境问题应修正环境；真实实现缺陷应修正实现。
- 测试未匹配路由的回退行为时，提供局部 resolver 替身返回未匹配结果，保留回退断言；参考 [login-redirect.test.ts](../../../web/src/utils/login-redirect.test.ts)。
- 只有当前行为明确承诺会产生日志时，才在单个用例内精确断言，并在结束后恢复替身。不全局静默 `console`、Vue 警告或 Vitest 日志，不将消音当作修复。

## 实现变更后的测试漂移

完成实现或测试精简后，继续对照当前代码和生产调用方检查：

- 删除、移动或重命名的组件、路径、字段和 API 是否仍被测试、fixture 或替身引用。
- 独立卡片等当前交互是否仍被旧的聚合提交断言约束，已移除的行为是否仍有正向或负向断言。
- 是否存在仅被旧测试调用、没有生产用途的遗留 helper，以及失去用途的脚本、依赖或文档入口。

将仍有效的断言迁移到当前行为，删除失效或超出范围的测试和辅助代码。移除生产 helper 前确认没有生产调用方；不要为了旧测试恢复已删除行为，或增加兼容别名、默认值兜底、新旧逻辑并存。同步修正受影响的活文档，不改写归档材料。

## 验证与交付

修改前端实现或测试后，从仓库根目录进入 `web/` 运行项目固定版本的 Yarn：

```powershell
cd web
corepack yarn lint:fix
corepack yarn typecheck
corepack yarn test --reporter=default --silent=false --no-color
```

普通单元测试即可，不运行前端覆盖率。根目录 `task test -- --cov` 的覆盖率只属于 Go，前端仍运行普通测试。仅修改实践文档或 skill 时，核验文档、链接及 skill 结构即可。

交付说明保留或删除了哪些测试、警告是否消除、漂移是否修正及验证结果。暂存和提交按用户授权执行；检查请求本身不代表授权扩大修改范围。
