# 代码规范

## 通用

### 1. 禁止 Git 写入操作
- ❌ 不要执行任何 git 写入操作
- ✅ 除非用户明确授权


### 2. 不明白就问，不要瞎编
- ❌ 不确定的 API 用法不要猜测
- ❌ 不确定的组件属性不要瞎写
- ✅ 不明白时先问用户
- ✅ 或使用 readFile/grepSearch 查看文档和示例代码
- ✅ 或使用 webFetch 查看在线文档


## 前端

### 1. 开发服务器由用户管理
- ❌ 不要自主启动/停止/重启开发服务器
- ✅ 用户自行管理开发服务器

### 2. 每次代码变更后必须执行（强制）
```bash
yarn lint --fix
yarn typecheck
```
有错误必须立即修复，不能提交有错误的代码。
