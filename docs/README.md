## 文档维护原则

1. **单一职责**：每个文档专注一个主题
2. **及时更新**：代码变更时同步更新相关文档
3. **归档过时内容**：已决策或过时的文档移至 `archive/`
4. **交叉引用**：相关文档之间建立链接

## 贡献指南

- 新增文档请遵循现有目录结构
- 重要决策和架构变更需要文档记录
- 文档使用中文编写，代码示例使用英文注释
