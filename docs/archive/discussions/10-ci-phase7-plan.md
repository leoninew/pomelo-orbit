## 📋 Phase 7 目标

## 🎯 优先级排序

### P0 - 必须完成（核心功能）

#### 1. 模板市场页面 ✨
**目标：** 让用户能方便地浏览和使用内置模板

**功能点：**
- 模板卡片展示（名称、描述、变量数量）
- 内置模板标记
- 查看模板详情（YAML 内容、变量声明）
- 一键创建项目（基于选中的模板）

**技术实现：**
- 新增路由：`/ci/template-market`
- 新增页面：`TemplateMarketPage.vue`
- 复用现有的模板详情组件
- 集成项目创建流程

**预计工时：** 2-3 小时

#### 2. 用户快速上手指南 📚
**目标：** 帮助用户快速理解和使用 CI 系统

**内容：**
- CI 系统概述（Project、Template、Credential、Run 概念）
- 快速开始（5 分钟创建第一个 CI 项目）
- Webhook 配置指南（GitHub / GitLab）
- Pipeline YAML 编写指南
- 变量系统说明
- 常见问题 FAQ

**文件位置：** `docs/user-guide/ci-quickstart.md`

**预计工时：** 2-3 小时

---

### P1 - 应该完成（体验优化）

#### 3. Pipeline YAML 编辑器增强
**功能点：**
- YAML 语法高亮（Monaco Editor）
- 基础的自动补全（version、steps、image、commands）
- 变量占位符提示（{{ VARIABLE_NAME }}）
- 实时语法校验

**预计工时：** 3-4 小时

#### 4. 变量配置表单增强
**功能点：**
- 从模板的 variable_declarations 自动生成表单
- 显示变量描述和默认值
- 区分必填和可选变量
- 敏感变量（password）使用密码输入框

**预计工时：** 2-3 小时

#### 5. 实时日志推送（SSE）
**功能点：**
- Job 日志实时推送到前端
- 自动滚动到底部
- 日志搜索和过滤

**技术实现：**
- 后端：FastAPI SSE endpoint
- 前端：EventSource API
- 日志缓冲和批量推送

**预计工时：** 4-5 小时

---

### P2 - 可以完成（高级功能）

#### 6. Job 树可视化
**功能点：**

- 依赖关系可视化（depends_on 箭头）
- 实时状态更新（颜色标记）

**技术实现：**
- 使用 D3.js 或 ECharts 绘制树形图
- 递归渲染 Job 树结构

**预计工时：** 5-6 小时

#### 7. API 文档更新
**功能点：**
- 更新 OpenAPI/Swagger 文档
- 添加 CI 相关的所有 API
- 提供 API 使用示例

**预计工时：** 1-2 小时

#### 8. 部署配置示例
**功能点：**
- Docker Compose 配置示例
- 环境变量说明
- 数据持久化配置
- 反向代理配置（Nginx / Traefik）

**预计工时：** 1-2 小时
