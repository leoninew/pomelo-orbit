# 前端界面规范

前端采用中性画布、开放数据区和克制的文字层级，在现有页面与共享组件上演进。保持页面已有的信息组织和操作入口，通过布局、间距、分隔与交互状态表达层次。

## 布局与主题

- 桌面顶栏高 64px，展开侧栏宽 208px。顶栏模块与侧栏选中项使用透明底色，通过蓝色文字和细线表示当前位置；会话选中项使用浅色底和细线。
- 列表使用开放数据区，详情按内容分节，以浅中性色背景区分区域，不添加卡片外框或阴影。输入控件、菜单、浮层与必要分隔保留清晰边界。
- 浅色、深色及 Teleport 浮层共用主题变量。蓝色用于交互、选中和焦点，成功、警告与危险状态沿用语义色，并配合文字或图形。
- 首页保留四张原图，指标组成连续摘要区，最近记录使用开放表格。仓库保留八列及现有搜索、分页和行操作。
- 项目切换器是带项目图标、名称和下拉箭头的按钮。窄屏表格在自身容器内横向滚动，页面与操作区保持可见。

## 文字

| 角色 | 规范 |
| --- | --- |
| 正文、表单及普通控件 | 14px，行高 22px，常规字重。 |
| 辅助信息、表头、日期及表格文字操作 | 12px，行高 20px，常规字重。 |
| 既有标题与指标 | 沿用现有 14px / 16px 角色，使用常规字重。 |
| 品牌名称 | 500 字重。 |

保持已有标题层级，不额外添加页面标题或通过加粗、放大普通文字制造层次。实体名称链接使用正文色，文字操作使用交互色，危险操作使用危险色。

## 表格

- 所有表格使用 `.app-data-table`，统一浅色表头、左对齐、横向行线和单元格间距，不叠加网格外框。
- 普通数据行高 52px，单元格水平内边距 12px、垂直内边距 8px。多行内容和编辑控件自然撑高；36px 单行控件对应约 53px 行高。
- 文字操作单元格使用 `.app-table-actions`，统一链接与按钮的字号、行高和字重。编辑、详情、删除、取消、重置及禁用状态遵守同一规则，不能根据颜色类分别定义字号。
- 表单输入保持 14px，避免继承操作列的 12px。列宽按内容分配，长文本复用截断与提示组件。

## 表单与浮层

- 普通变量、名称、用户、附加组、路径和资源值使用 `AppInput`；策略等枚举值使用 `SelectControl`。
- 命令、脚本、JSON、说明及其他多行内容使用 `AppTextarea`。服务组件的运行用户和附加组使用单行框，入口命令与命令使用多行框。
- 弹窗、抽屉、菜单和提示复用 `AppDialog`、`AppDrawer`、`AppActionMenu`、`AppPopover` 等共享组件。长表单正文独立滚动，标题与底部操作区保持可见，操作按钮允许换行。
- 加载、空数据、错误、禁用和键盘焦点沿用共享组件与语义样式。

共享主题、表格及控件规则位于 [style.css](../web/src/style.css)，工作区、导航和首页布局位于 [workspace.css](../web/src/styles/workspace.css)；字号与字体配置位于 [tailwind.config.js](../web/tailwind.config.js)。
