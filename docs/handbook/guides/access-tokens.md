# 访问令牌

个人访问令牌（PAT）用于本地 [MCP](../reference/mcp.md) 和[环境 CLI](../reference/cli.md)，代表令牌所有者。普通 Web API 使用浏览器 JWT。

## 创建与使用

1. 打开“系统管理 → 访问令牌”，这里只管理自己的令牌。
2. 填写用途名称，选择有效期：永不过期、30 天、90 天或 365 天。界面默认为永不过期，按用途主动选择。
3. 创建后核对名称、到期时间，将完整令牌存入凭据管理工具，再配置客户端。

当前令牌可在列表中再次显示和复制。系统保存认证哈希及加密原值；旧记录若没有可恢复值，显示 `-`，需创建替代令牌。

## 权限范围

PAT 使用所有者当前权限和项目成员关系。每个客户端单独创建令牌便于撤销，但没有每令牌只读或固定项目范围；名称也不限制权限。

MCP 每次工具调用前重新校验 PAT。CLI 业务入口在打开应用服务时认证，撤销不能保证运行中的长命令即时中断。已受理的任务需另行查看或取消。

## 轮换与撤销

轮换时先创建替代令牌，更新并验证客户端，再撤销旧令牌。

在令牌列表撤销并刷新核对；已撤销令牌不能恢复。怀疑泄露时优先撤销受影响令牌，再检查已执行操作。

实例[主密钥](../operations/secrets.md)保护令牌的可恢复原值，认证仍按哈希匹配，更换主密钥不能替代撤销 PAT。
