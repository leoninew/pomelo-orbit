# 组件

一个组件对应版本中的一个 Compose 容器声明。例如订单应用的 `api` 和 `redis` 是两个组件；服务则管理整组组件的运行绑定。

## 声明组件

在未发布版本中点击“添加组件”，填写组件名、镜像、拉取策略和重启策略。组件名在版本内唯一，以小写字母开头，只含小写字母、数字和连字符。

保存后进入组件详情，各配置组分别保存：

| 配置组 | 填写内容 |
| --- | --- |
| 入口和命令 | 参数数组；没有覆盖需求时保留镜像默认行为 |
| 环境变量 | 固定值或完整的[服务变量占位符](../reference/service-variables.md) |
| 挂载 | 数据目录、文件、受控文件或命名卷 |
| 端口 / 暴露 | 协议、容器端口、暴露模式及宿主端口 |
| 依赖与健康检查 | 同版本组件间的启动条件和健康检查命令 |

## 选择端点暴露模式

| 模式 | 访问方式 |
| --- | --- |
| `internal` | 容器网络内访问，不发布宿主机端口 |
| `local` | 绑定执行主机回环端口 |
| `host` | 绑定指定宿主机地址与端口 |
| `gateway` | 仅 HTTP；服务加入 Traefik 网络并部署后生成域名入口 |

`gateway` 域名为 `<组件名>.<服务编码>.<内网域名>`，DNS 需另行配置。独立域名或 TCP 转发使用[自定义路由](./routes.md)。

挂载路径、受控文件和依赖的具体限制见[Compose 生成规则](../reference/compose.md)。完成配置后返回版本预览；镜像拉取、端口占用和业务健康在部署时验证。
