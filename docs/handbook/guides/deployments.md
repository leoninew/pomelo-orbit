# 部署记录

每次部署、重启或停止都生成一条独立记录，冻结当次版本、目标和目录。服务长期存在，部署记录描述其中一次操作。

## 查看本次结果

| 位置 | 检查内容 |
| --- | --- |
| 部署记录 | 服务、操作类型、版本、工作目录、终态、错误和日志 |
| 服务详情 | 当前容器、健康检查、实际镜像及更新的操作 |
| 业务入口 | 实际 HTTP / TCP 响应；使用域名时继续检查 DNS、路由与证书 |

任务受理后仍需等待后台执行。当前服务状态以最新受理的操作为准，旧任务结果不能覆盖新操作。

## 状态检查

容器被外部工具修改时，可在服务列表点击“状态检查”，查看容器实况与记录差异。审阅后点击“更新状态”同步记录；需要修复容器时仍应按实际情况部署或处理故障。

## 超时与失败

- 页面超时或连接中断后，先按本次编号查询记录，确认操作是否仍在执行。
- 执行失败时，检查本次日志中的镜像、目录、端口或目标错误。
- 有状态业务的失败恢复按[备份与恢复](../operations/backup.md)处理；重新部署不会自动恢复数据。

常见症状与检查入口见[故障定位](../operations/troubleshooting.md)。
