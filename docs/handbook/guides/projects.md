# 项目

项目组织成员、应用、应用流水线和服务。每个项目只有一个 CI/CD 共用的[执行环境](./environments.md)。

## 创建项目

1. 打开“系统管理 → 项目”，点击“创建项目”。
2. 填写名称和编码。编码以小写字母开头，可含小写字母、数字、`+`、`.`、`-`，最长 32 位；创建后不可在界面修改。
3. 选中新项目，进入初始化向导配置执行环境。创建者自动成为初始成员。

需要不同 Docker 执行目标时，分别规划项目。同一项目下的两个服务仍在同一执行环境运行。

## 哪些资源由项目管理

| 项目内资源 | 实例共享资源 |
| --- | --- |
| 应用、版本、服务、应用流水线、执行记录、部署对话 | 代码仓库、仓库凭据、阶段模板、流水线模板、用户和系统角色 |

切换项目会切换业务上下文，共享资源仍是同一份配置。项目隔离也不隔离宿主机端口、容器名或磁盘目录。

## 维护成员

在项目详情的成员区域添加已有的启用用户，或移除成员。系统角色和项目成员分别管理：有系统权限的用户仍须加入项目。

- 当前界面需要 `user:read` 以加载用户候选；候选来自前 100 个用户，并过滤禁用账号和已有成员。
- 当前没有项目所有者、只读成员等成员角色。成员管理接口检查操作者是否属于项目。
- 移除成员前保留其他维护者，系统不保证阻止移除自己或最后一位成员。

移除成员阻止后续项目访问，已受理的构建、部署和运行容器仍会继续。账号与系统权限的维护分别见[用户](./users.md)和[角色与权限](./roles.md)。
