# 代码仓库

仓库记录源码地址、默认分支和构建变量，供[流水线](./pipelines.md)绑定。仓库跨项目共享，修改会影响所有引用它的流水线。

## 选择源码类型

| 类型 | 要求 | 限制 |
| --- | --- | --- |
| 远程 Git | 可访问的 Git 地址；私有仓库绑定[仓库凭据](./repository-credentials.md) | 令牌认证及 SSH CI 使用 HTTPS 地址 |
| 本地目录 | 后端能读取的普通 Git 工作目录或裸仓库 | 不支持 linked worktree、普通文件目录或 SSH CI；不绑定 Git 凭据 |

本地目录由后端和实际 Docker 执行侧读取。未提交的修改不等于构建某个 ref 时会取到的内容。

## 登记仓库

1. 打开“持续集成 → 仓库”，填写名称和编码。编码只含小写字母、数字、连字符或下划线，创建后不可修改。
2. 选择类型并填写源码位置。私有远程仓库绑定合适的凭据；地址本身不携带令牌或密码。
3. 填写实际存在的默认分支，保存并核对仓库详情。

保存后，通过流水线的取源码阶段验证网络、认证及 ref。

## 分支与变量

- 默认分支为运行提供初始 ref，触发时仍可选择分支或标签。
- 仓库变量参与使用它的流水线取值；同名有效值优先于阶段和全局配置，详见[构建变量](../reference/ci-variables.md)。
- 排查某次执行时看[运行记录](./runs.md)中的 ref 和变量快照。

仍被流水线引用的仓库不可删除。删除仓库记录只移除配置，源码工作区、远端仓库和上游令牌需另行处理。
