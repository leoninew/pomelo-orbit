# 仓库凭据

在“持续集成 → 凭据”创建，供远程仓库绑定。凭据跨项目共享；名称在共享范围内唯一。

## 选择类型

| 类型 | 填写内容 | 当前 Git 执行支持 |
| --- | --- | --- |
| `github_token` | GitHub 令牌 | 支持 HTTPS Git |
| `gitee_token` | `用户名:令牌` | 支持 HTTPS Git，两部分都要填写 |
| `gitea_token` | `用户名:令牌` | 支持 HTTPS Git，两部分都要填写 |
| `git_ssh` | SSH 私钥 | 可保存，当前流水线不支持用它取源码 |
| `registry_token` | 镜像仓库凭据 | 不用于 Git 认证；绑定仓库不会自动登录镜像仓库 |

环境通过 SSH 连接时，源码仍应使用 HTTPS Git。环境 SSH 密钥与这里的 Git 身份分别配置。

## 创建与更新

1. 创建名称明确、权限满足目标仓库的凭据。
2. 在[代码仓库](./repositories.md)中绑定，使用取源码阶段验证。
3. 更新共享凭据前确认引用范围；类型不可编辑，需要换类型时新建再重新绑定。

仍被仓库引用的凭据不能删除。删除记录后，上游令牌的撤销仍需在 Git 服务中完成。

::: warning 导出包含明文秘密
详情可显示原值，导出文件包含解密后的凭据内容。将导出文件按秘密保管，不提交到 Git 或作为公开附件。导入只接收可信文件。
:::
