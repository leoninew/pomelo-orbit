# 自定义路由

自定义路由给 HTTP 或 TCP 流量指定匹配规则和下游。保存后需要预览并确认同步，发布到 Traefik File provider。

组件已有 `gateway` 端点时，可直接随服务部署生成 Docker provider 入口；需要独立域名或其他下游地址时使用自定义路由。

## 创建路由

打开“自定义路由”，填写编码、域名和协议。编码以小写字母开头，只含小写字母、数字和连字符，末尾不能为连字符，最长 32 位。

| 协议 | 匹配与目标 | 运行前提 |
| --- | --- | --- |
| HTTP | Host 与路径前缀，转给服务 HTTP 端点或高级下游地址 | 目标从网关侧可达；路径前缀不会自动删除 |
| TCP | 按监听端口转给服务 TCP 端点 | 网关已有 `tcp<端口>` 静态入口和端口映射 |

HTTP 高级下游地址使用 `http[s]://host[:port]`，不含路径；其中的回环地址指网关容器。TCP 不按域名或 SNI 分流，不能在此配置 HTTP 路径或 HTTPS 证书。

TCP 端口范围 1–65535，80、443、8080 为保留端口。平台检查已启用 TCP 路由与运行中组件端点的冲突；宿主机其他进程占用仍需检查。路由同步不会添加静态入口、端口映射或防火墙规则。

## 发布变更

1. 创建后初始为停用。核对目标，需要 HTTPS 时配置[证书](./certificates.md)。
2. 点击启用或停用，再点击同步，查看待发布意图。
3. 详情页预览当前路由；列表页预览整个项目，可能包含已删除路由的遗留撤销项。
4. 核对规则、入口、目标和证书后确认，查看每项结果。
5. 到“Traefik 路由”核对加载规则，从客户端检查实际访问。

预览会读取执行目标与网关；配置或运行文件变化后需重新预览。批次可能部分成功，失败后查看具体结果再处理。

## 撤下入口

选择停用 → 同步并确认撤销 → 检查实际规则 → 删除不再需要的记录。当前只允许删除停用路由；DNS、业务服务和外部资源分别清理。
