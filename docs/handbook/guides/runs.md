# 运行记录

每次提交流水线都会生成独立运行记录，保存定义、变量和执行目标快照。在“持续集成 → 运行记录”或流水线详情中查看。

## 检查一次运行

1. 核对流水线版本、仓库 ref、定义快照与变量快照。
2. 查看各阶段状态、退出码及日志，定位第一处失败。
3. 查看[制品](./artifacts.md)是否齐全；绑定业务应用时再核对生成版本。

脚本成功之后仍有制品收集和版本派生，最终结果以完整运行终态为准。历史输入以该记录的快照为准，当前编辑器反映的是最新配置。

## 受理限制

同一仓库存在活跃运行时，新运行可能被拒绝。排队后目标或 SSH 凭据变化，任务会因快照与当前环境不一致而被拒绝；核对当前环境后再重试。

## 取消、重试与清理

| 动作 | 行为 |
| --- | --- |
| 取消 | 请求结束等待中或运行中的任务；已完成的脚本写入和镜像推送保留 |
| 重试 | 按当前流水线和环境创建新运行，关联原记录，并复用允许保留的原非系统变量值 |
| 删除 | 只适用于已结束记录，涉及历史与运行文件；先保留需要的制品和故障证据 |

重试会重新校验当前配置，也可能取到不同提交或镜像。含外部写入的阶段在重试前先确认原执行结果。
