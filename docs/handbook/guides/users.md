# 用户

用户是实例登录身份。账号创建后，分别分配[系统角色](./roles.md)和[项目成员关系](./projects.md)。

## 创建账号

1. 打开“系统管理 → 用户”，需要 `user:read` 和 `user:write`。
2. 填写唯一用户名、有效且唯一的邮箱和密码。密码当前限制为 6–36 字节。
3. 保存后检查启用状态，再配置角色及项目成员。

密码登录使用**邮箱**。新账号默认启用，没有自动分配角色或加入项目。

## 密码维护

| 操作 | 要求 |
| --- | --- |
| 修改自己的密码 | 用户菜单 → 修改密码，需要旧密码 |
| 管理员重置 | 需要 `user:write`；重置另一位有 `role:write` 的用户时，操作者也需要 `role:write` |
| 编辑用户但保留密码 | 密码留空 |

修改密码和退出 Web 登录不会统一撤销已签发的 JWT 或 PAT。个人令牌泄露时到[访问令牌](./access-tokens.md)显式撤销。

## 禁用与删除

禁用阻止账号后续认证；重新启用后，仍有效的令牌可能继续使用。删除会移除账号、角色关联和项目成员关系，登录历史保留。

当前不能禁用或删除正在操作的自己。账号操作不会停止已受理任务或运行容器，变更前确认其他维护者仍有管理入口。
