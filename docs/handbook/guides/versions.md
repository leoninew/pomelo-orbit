# 版本

版本保存一组组件的镜像、配置和依赖，是应用的一份部署定义。同一版本可被多个服务选择。

## 编辑版本

1. 在应用详情打开初始版本，或新建一个版本。
2. 在未发布版本中添加[组件](./components.md)，配置镜像、环境变量、挂载、端点和依赖。
3. 点击“预览”，检查生成的 Compose 定义。
4. 发布版本，固定组件定义。

版本预览只使用声明；某个服务的实际变量与覆盖应在[服务预览](./services.md)中检查。

## 发布与后续变更

| 操作 | 结果 |
| --- | --- |
| 发布 | 变为 `published`，不能直接编辑组件定义 |
| 复制 | 保留原版本，创建可编辑的新版本 |
| 撤回发布 | 恢复为未发布，允许编辑 |

这些操作只改变定义。要更新运行容器，由服务选择相应版本后提交部署。服务可以选择未发布版本，选择前自行确认交付内容。

流水线也能从[镜像制品](./artifacts.md)派生未发布版本。被服务引用的版本不能直接删除。
