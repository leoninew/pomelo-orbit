# Pomelo Orbit

Pomelo Orbit 是自托管 CI/CD 平台，用于管理流水线、应用部署和 Traefik 网关。它支持在本机和 SSH 环境中执行 Docker Compose 部署。

项目的后端使用 Go，前端使用 Vue 3。Pomelo Orbit 面向 Compose 工作流，不以 Kubernetes 或多集群编排为主要使用路径。
