# 故障定位

先记录失败时间、当前项目、操作类型、运行或部署编号，以及第一条相关错误。按失败所在层次查找。

## 页面与身份

| 症状 | 检查入口 |
| --- | --- |
| 页面打不开 | 实例进程、监听地址、反向代理和网络 |
| 登录失败 | 邮箱、账号启用状态和实例地址，见[用户](../guides/users.md) |
| 看不到项目或操作被拒绝 | [项目成员](../guides/projects.md)和[系统权限](../guides/roles.md)分别检查 |
| MCP / CLI 认证失败 | PAT、配置根目录、profile、数据库与主密钥 |

## 构建与部署

| 症状 | 优先检查 |
| --- | --- |
| 环境无法执行 | [目标配置、SSH 授权、主机指纹、Docker / Compose](../guides/environments.md) |
| 流水线无运行入口 | 当前是否为共享模板，先复用为应用流水线 |
| 取源码失败 | [仓库地址、认证、ref](../guides/repositories.md)和执行侧网络 |
| 脚本或收集失败 | 本次[运行快照与阶段日志](../guides/runs.md)、制品声明和输出 |
| 服务预览缺变量 | [服务变量](../reference/service-variables.md)、继承与覆盖 |
| 任务长时间等待 | 维护者检查 Worker、队列与当前目标 |
| 部署失败 | 本次[部署日志](../guides/deployments.md)、镜像、目录权限和端口占用 |

请求超时后先查询原记录，确认已发生的操作，再决定重试。改目标或目录不会迁移旧数据。

## 容器运行但无法访问

沿客户端到业务逐层检查：

1. **DNS**：解析地址、缓存、Cloudflare 代理；`localhost` 指当前访问设备。
2. **端口**：宿主机映射、防火墙与实际网关入口。
3. **TLS**：域名、有效期、客户端信任和签发日志。
4. **路由**：Traefik 实际加载的 Host、路径、入口及下游；路径前缀不会自动剥离。
5. **业务**：容器网络、监听端口、健康检查和组件日志。

组件 `gateway` 端点通过服务部署生效，[自定义路由](../guides/routes.md)通过同步生效；TCP 静态入口和端口映射需预先准备。

## 设置与自动化

配置未生效、revision 冲突和文件访问错误见[系统配置](./configuration.md)。解密错误先检查[密钥与数据库是否匹配](./secrets.md)。

[部署对话](../guides/deployment-dialogue.md)断流或缺少历史时，先核对工具涉及的真实资源和部署记录。模型请求失败后，已提交操作仍可能执行。

## 问题反馈

向 [GitHub Issues](https://github.com/leoninew/pomelo-orbit/issues)提供实例版本、安装方式、目标类型、最少复现步骤、时间与操作编号，以及必要的脱敏错误。日志、预览和配置分享前移除密码、令牌、私钥及数据库连接秘密。
