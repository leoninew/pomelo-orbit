# 构建变量

构建变量供阶段脚本和制品的名称、引用、命令使用，采用 Liquid 语法。解析后的阶段变量也作为阶段环境值传入。

## 引用与优先级

简单引用写作 <code v-pre>{{ APP_MODE }}</code>，引用默认值写作 <code v-pre>{{ APP_MODE | default: "test" }}</code>。

同名配置按以下顺序选第一个有效值：

1. 仓库变量。
2. 流水线阶段变量。
3. 流水线全局变量。
4. 当前引用的默认值。

每份配置先取“值”，缺失时再取“默认值”；未填、空串和纯空白都视为无有效值。同名同作用域不能重复，变量名为 `^[A-Za-z][A-Za-z0-9_]*$`。

## 内建上下文

| 名称 | 内容 |
| --- | --- |
| `repository_code` | 仓库编码 |
| `repository_url` | 源码位置 |
| `repository_ref` | 本次选择的 ref，未另选时用默认分支 |
| `runtime_datetime` | 本次运行 UTC 时间，`YYYYmmdd-HHmmss` |

内建值不接受普通自定义变量覆盖。ref 在运行对话框中选择，其余值提前在仓库或流水线配置。

## 嵌套规则

- “值”可用简单引用嵌套，如 <code v-pre>{{ repository_code }}-web</code>；不支持嵌套过滤器、点路径或标签。
- “默认值”只填普通文本。未知引用、循环引用和不完整表达式会被拒绝。
- 全局值不能引用阶段私有值，各阶段私有值也不互通。被高优先级遮住的无效定义仍需修正。
- 当前模板字段拒绝 `${NAME:-value}` 等 shell 默认值语法。

## 检查实际取值

查看[运行记录](../guides/runs.md)的变量快照。重试使用当前定义并复用允许保留的原值，需同时核对原记录。

Liquid 插入脚本文本不会代替 shell 参数转义，敏感标记也不会自动清理脚本日志。构建变量与[服务变量](./service-variables.md)分别配置，不会自动传递。
