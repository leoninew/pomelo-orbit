# 服务容器版本关联
最后修改时间: 2026-07-28 15:23:46

Review status: Accepted

## Background

服务详情页的“最近成功版本”是服务记录的推断字段，不能证明当前容器实际运行的版本；容器状态查询也没有版本信息。

## Goal

- 删除“最近成功版本”及其持久化、接口和页面展示。
- 在每次 Compose 渲染时为每个容器写入版本 ID 和版本标签。
- 服务详情的容器表读取容器标签并展示实际关联版本。
- 同步更新服务建表迁移与当前运行中的 SQLite 数据库。

## Non-goal

- 不回填或重建此前已运行的容器标签。
- 不改变部署、停止和重启的生命周期语义。

## User scenarios

用户刷新服务详情的容器表，可直接看到每个容器由哪一个版本渲染；重新部署后，所有该服务的容器带有新的版本关联。

## Acceptance

- `service` 表不再含 `last_successful_version_id`。
- 服务接口与详情页不再暴露或展示“最近成功版本”。
- Compose 服务包含 `pomelo.orbit.version-id` 和 `pomelo.orbit.version-label` 标签。
- 状态接口读取容器标签，并向前端返回版本 ID 与标签。
- 容器表可链接到相应版本；历史未标记容器显示空值。

## Open questions

暂无需要用户确认的未决事项。

## Decisions

容器标签是容器与版本的唯一运行时关联来源；不以 Service 当前的 `version_id` 猜测容器版本。

## Risk

首次发布前已经运行的容器没有新标签，需在下一次部署后才会显示版本。
