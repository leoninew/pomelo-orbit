# 服务挂载源路径模式
最后修改时间: 2026-08-09 16:54:54

Review status: Accepted

## Background

Version 组件编辑页曾允许将目录或文件挂载标记为宿主机路径。该设置把实际部署位置混入 Version 声明；填写 Windows 绝对路径时，错误还会被显示到背景页面的 Toast。

## Goal

- Version 的挂载仅声明挂载类型、默认源和容器目标，不在编辑界面提供宿主机路径模式。
- Service 组件覆盖拥有实际源路径及其“来源是宿主机路径”模式；目录和文件可使用绝对宿主机路径。
- Version 挂载模态的本地或保存失败留在当前模态内显示。
- Service 挂载列表与 Version 组件挂载列表使用相同的类型、源路径、目标路径、只读和操作列；编辑源路径与宿主机路径模式使用独立模态窗，不在表格单元格内联编辑。
- Service 返回的有效运行配置错误属于整页异步反馈，以 Toast 展示，不归属到环境变量卡片；提示应停留足够时间供用户阅读。

## Non-goal

- 不重构网关 compile 所需的内部挂载声明。
- 不新增数据库状态组合约束、数据异常分析或异常兜底分支。
- 不提供面向已存在数据库的兼容升级或数据回填。

## Acceptance

- 服务页编辑目录或文件挂载时可选择宿主机路径并保存绝对路径。
- 未选择宿主机路径的绝对源路径被服务用例以明确业务校验拒绝。
- Version 挂载模态不展示宿主机路径开关，保存失败不会触发背景页面 Toast。
- 新建数据库的 Service 挂载覆盖表直接包含可空路径模式列；不为历史数据增加迁移、默认值或回填逻辑。
- Service 挂载编辑模态展示类型、源路径、目标路径和只读字段；只允许修改源路径和宿主机路径模式，其余字段作为 Version 声明只读展示。
- 模态确认仅更新当前 Service 页面草稿；页面顶部的保存命令仍是唯一持久化入口。
- 有效运行配置不可用时，环境变量区域不显示与其无关的表单错误，页面显示包含具体原因的 Toast。

## Risk

- 本任务只调整空库基线；已存在的数据库不提供路径模式列的兼容升级或回填。
