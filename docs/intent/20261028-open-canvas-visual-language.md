# Intent / 意图：全系统前端设计语言统一
最后修改时间: 2026-10-28 18:09:23

## 审查状态

Accepted

## 背景与目标

在现有前端中引入用户认可的现代化设计语言，保留熟悉的页面入口、业务内容和操作流程。首页与仓库页作为设计样例，再将同一套布局、文字、表格和控件规则推广至全系统。现行规则见[前端界面规范](../frontend-design.md)。

范围包括导航与工作区、列表与详情、对话、登录、菜单、模态窗、抽屉和确认。通过中性画布、开放数据区、透明导航选中态及克制的文字层级提升一致性；保留首页四张原图、仓库八列和项目切换控件。

不调整后端、接口、权限、路由路径、业务字段或操作流程，不新增页面标题、虚构数据和第二套组件体系。原型提供视觉依据，产品继续复用现有 Vue、Tailwind、Reka 和共享组件。

## 场景与验收

用户从原有入口浏览列表和详情，在同一视觉体系下使用搜索、分页、表单、确认和日志抽屉；切换主题或使用窄屏时，内容与操作仍可辨识。

- A01：全部路由使用共享主题和外壳，菜单与 Teleport 浮层保持一致。
- A02：首页原图、指标和最近记录，仓库八列及现有搜索、分页、操作完整；不改变业务和接口契约。
- A03：所有表格共用样式，普通行高 52px，多行和内嵌控件自然撑高。操作文字统一为 12px / 20px / 常规字重，覆盖链接、编辑、详情、删除、取消、重置和禁用状态。
- A04：普通变量和单值配置使用单行框，策略使用下拉框，命令及多行内容使用文本域；保持现有校验和提交转换。
- A05：模态窗、抽屉、确认及加载、空、错误状态复用共享组件；浅/深色与窄屏布局保持可用，长表单正文滚动且操作区可见。
- A06：完成前端 lint、类型检查、轻量单测、构建及实际页面核对，记录结果和未覆盖边界。

## 评估、决策与风险

工作量和复杂度中等，业务风险较低；共享样式的影响面较大，需要核对列表、详情和特殊视图的局部覆盖。主要交付共用同一套样式与组件，保持单任务、主会话串行实施；候选子任务与依赖不适用。

复用现有主题变量和组件，不保留两页试用分支；设计稿中的描边效果在前端用明确的行线实现。必要上下文为现有组件、实际 diff、页面截图与浏览器采集结果。浏览器核对以真实记录为基础，不通过提交业务数据制造验证状态。

暂无需要用户确认的未决事项；未覆盖的业务状态写入验证报告，不推定通过。
