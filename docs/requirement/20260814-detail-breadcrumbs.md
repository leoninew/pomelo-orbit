# 详情页面包屑
最后修改时间: 2026-08-14 18:38:00

Review status: Accepted

## Background

当前详情页仅提供返回按钮。持续部署中的应用、版本、服务和组件存在多级实体关系；持续集成中的仓库、凭据、流水线、阶段、运行、制品和快照详情也缺少当前位置与可预测的列表返回入口。

## Goal

为持续部署与持续集成的详情页及网关编辑页提供一致、可访问、可本地化的面包屑导航；只有存在真实父实体链路的页面才声明 breadcrumb，并保留现有返回按钮与操作区。

## Non-goal

- 不调整 API 路由或后端响应契约。
- 不以额外串行请求补齐缺失的父实体名称。
- 不改变既有详情页的数据加载、操作权限或返回行为。

## User scenarios

- 用户在版本组件页可跳转回所属版本或应用。
- 用户在服务组件配置页可跳转回所属服务或应用。
- 用户在持续集成任一详情页可识别当前资源所属列表；快照可跳转回流水线。
- 用户在网关编辑页可返回网关详情或网关列表。

## Acceptance

- 提供一个共享面包屑组件，使用语义化标记、窄屏可用；当前页由详情页标题承担。
- 持续部署详情/编辑页与持续集成详情页均接入面包屑。
- 路径中的可跳转节点使用 RouterLink，面包屑展示模块名与资源集合，不重复渲染当前页标题。
- 标题、状态、操作按钮和既有返回按钮保留；文案支持中英文。
- 前端 lint 与类型检查通过。

## Open questions

暂无需要用户确认的未决事项。

## Decisions

- 为避免扩大本次 API 范围，页面仅使用已加载数据声明真实父实体路径；不补齐父实体实例名。
- 为避免面包屑与 h1 重复，面包屑仅展示模块到资源集合的导航路径，当前页由页面标题承担。
- 面包屑置于详情标题上方，并不取代返回按钮。

## Risk

- 部分响应未提供完整祖先展示名，因此个别路径不会显示完整的实体名称链；后续如需补齐，应统一扩展详情响应而非在前端引入请求瀑布。
