## 统计方法

- 扫描 `web/src` 中全部自定义 `.vue` 文件，以及引用它们的 Vue、TypeScript、TSX 源文件。
- 用 Vue SFC 和 TypeScript 语法树读取静态 import、export 与路由的动态 import；解析 `@/` 和相对路径。排除测试、类型声明、纯类型导入、注释和文档示例。
- “引用文件数”按直接引用组件的不同生产源文件计数。同一文件引用或渲染多次仍计一次，循环渲染不累加。它不是组件实例数或页面访问次数。
- 页面和根组件单列，避免把路由引用当作共享组件复用。间接使用结合调用链检查，不能只按次数决定删除、合并或移动。
- 审视前指本轮职责审视开始时，包含此前已完成的筛选和输入控件修改；整理后指本轮目录和粒度调整完成后。
