# `run.py` — 同时启动本地开发服务

Doc role: local script reference。与代码冲突时以代码为准。

## 用途

同时启动后端热重载服务和前端开发服务器：

- 后端：`air -c .air.server.toml`，工作目录为仓库根目录；
- 前端：`yarn dev`，工作目录为 `web/`。

## 前置条件

从仓库内执行，且本机可找到 `air` 与 `yarn` 命令。前端依赖应已按项目要求安装。

## 用法

```bash
python scripts/run.py
```

脚本没有只读模式或命令行参数；执行即会启动开发服务。

## 停止行为

按 Ctrl+C 或发送 SIGTERM 时，脚本会停止它启动的两个进程组。先执行优雅停止；等待超时后会强制终止仍未退出的进程树。

## 安全边界

这是启动服务的命令，不应用于检查或验证脚本本身。它只管理自身启动的子进程，不会主动操作用户手动启动的开发服务器。
